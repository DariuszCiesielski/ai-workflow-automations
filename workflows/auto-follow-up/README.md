# Auto Follow-Up — Automatyczne Sekwencje E-mail

Workflow do automatycznego wysyłania follow-up e-maili po pierwszym kontakcie z leadem.

## Scenariusz

1. Lead wypełnia formularz kontaktowy lub zapisuje się na newsletter
2. System wysyła potwierdzenie (natychmiast)
3. Po 2 dniach — follow-up z dodatkową wartością (case study, poradnik)
4. Po 5 dniach — propozycja rozmowy / demo
5. Po 10 dniach — ostateczny follow-up z ofertą specjalną
