# Competitor Monitor — Monitoring Konkurencji

Workflow do automatycznego śledzenia zmian u konkurencji i generowania alertów.

## Scenariusz

1. Zdefiniuj listę konkurentów (URL, social media, produkty)
2. Cron codziennie sprawdza zmiany
3. AI analizuje co się zmieniło i ocenia wpływ
4. Alert (Telegram / e-mail) gdy wykryto istotną zmianę
